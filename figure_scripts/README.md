# Figure generation scripts

This folder follows the requirement that each figure has a corresponding generation script.

## Scripts and outputs

| Script | Output figure | Status in revised manuscript |
|---|---|
| `sync_fig_framework.sh` | `figures/fig_framework.png` | Optional helper; not used by the current revision |
| `generate_fig_robustness_curves.py` | `figures/fig_robustness_curves.pdf` | Active controlled-corruption figure |
| `generate_fig_five_seed_effects.py` | `figures/fig_five_seed_effects.pdf` | Active five-seed paired-effect figure |
| `generate_fig_confusion_binary.py` | `figures/fig_confusion_binary.pdf` | Legacy / excluded |
| `generate_fig_confusion_mosi_7class.py` | `figures/fig_confusion_mosi_7class.pdf` | Legacy / excluded |
| `generate_fig_silhouette_selected.py` | `figures/fig_silhouette_selected.pdf` | Legacy / excluded |
| `generate_fig_representation_pca.py` | `figures/fig_representation_pca.pdf` | Legacy / excluded |

Each script also saves a `.png` preview with the same base name.

## Required input files

Place either the extracted experiment folders or the zip files in the data root:

```text
mosi_baseline_seed5576.zip
mosi_ours_seed5576.zip
mosei_baseline_seed5576.zip
mosei_ours_seed5576.zip
```

or extracted folders with the same names. The scripts read:

```text
analysis/predictions.csv
analysis/repr.npz
```

## Example usage

Generate the figures used by the revised manuscript from the project root:

```bash
bash figure_scripts/generate_all_figures.sh . revision/overleaf_source/figures
```

This command reads the three-seed corruption records and the five-seed primary
run records from `experiments/`, then writes both active analysis figures to
the Overleaf figure directory. The framework diagram is the author-maintained
`fig_framework.pdf` and is not generated by these scripts.

The paired-effect figure requires these validation-MAE-selected primary runs:

```text
experiments/{mosi,mosei}_{baseline,ours}_valmae_seed{5576,42,2026,2027,3407}/metrics.json
```
